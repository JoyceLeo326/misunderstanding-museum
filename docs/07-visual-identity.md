# 07 · Visual identity

**Status:** v2.0 · Product identity complete

## 核心标志

误会博物馆的标志由两张错位的展签 / 对话框组成。它们相互遮挡，却在交叠处形成一扇可以穿过的门：误会不是品牌的终点，补足语境才是。

- 酒红展签：已经说出口、可以被逐字看见的内容；
- 灰蓝展签：另一人的经验、关系与前后文；
- 奶油色门洞：双方尚未共享的理解空间；
- 黄铜色门扇：由一个具体问题打开的下一步。

正式资产位于 `assets/brand/`：

- `museum-mark.svg`：主标志，用于网页页眉、页脚、favicon 与 PWA；
- `museum-brandkit-v1.png`：品牌应用板，覆盖主标志、横向组合、应用图标、入藏章、展签与票根；
- `README.md`：资产用途与法律表述边界。

## 图像语言

每件藏品固定使用一组 3:2 两联画：

1. **误读发生**：让字面、动作与错位期待同时可见；
2. **补上语境**：让确认、选择、边界或具体行动改变人物关系。

图像采用当代编辑插画、纸张颗粒和展签拼贴。人物与场景均为虚构复合，不把任何单一人物、国家或文化当成群体代表。网页中的来源说明必须保留，不得将插画描述为真实投稿照片。

## 响应式规则

- 首屏：移动端单列，桌面端将图像与语义展签并置；
- 馆藏卡：使用 4:3 中心裁切承载识别，完整叙事进入详情；
- 详情：使用 16:9 视窗和“误读发生 / 补上语境”双态切换；
- 320px：馆藏改为单列，任何图片或文字不得造成横向滚动；
- 所有图像保留具体 `alt`，不使用“插图”“配图”等无信息替代文本；
- 动效仅用于状态变化，并遵循 `prefers-reduced-motion`。

## 使用边界

- 不叠加地球、机器人、芯片或泛化 AI 光效；
- 不用国旗、口音、服饰或面部特征制造文化标签；
- 不把标志拉伸、旋转或换成未经定义的高饱和颜色；
- 标志是项目品牌识别设计，不宣称已获得任何地区的注册商标权。
